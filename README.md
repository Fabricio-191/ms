# @fabricio-191/ms

A powerful tool for parsing time formats and durations into their respective value in milliseconds. And also for converting milliseconds into a human readable format.

### Differences with [ms](https://www.npmjs.com/package/ms)

```diff
+ Can parse multiple languages
+ Can parse multiple units
+ Formatting has more options
+ Does not round while formatting
- When formatting, it's way slower than ms
```

## Installation

```bash
npm install @fabricio-191/ms
```

## Parse

First, build a parser for your language(s), then use it. If nothing can be parsed, it returns `null`.

```js
import { buildParse, LANGUAGES } from '@fabricio-191/ms';

const parse = buildParse(LANGUAGES.en);

parse('2 hours, 5.5 minutes and .3s');  // 7530300
parse('1 week 2 days');                // 777600000
parse('2 days 1 hour');                // 176400000
parse('1m10secs');                     // 70000
parse('5s50ms');                       // 5050
parse('1y');                           // 31557600000
parse('1d');                           // 86400000
parse('10h');                          // 36000000
parse('2.5 hrs');                      // 9000000
parse('.5m');                          // 30000
parse('100');                          // 100
parse('0 seconds');                    // 0
parse('-.5 mins');                     // -30000
parse('- 2m 30s');                     // -150000
parse('-3 days');                      // -259200000

// Spanish
const parseEs = buildParse(LANGUAGES.es);
parseEs('1 dia');                      // 86400000

// Japanese
const parseJa = buildParse(LANGUAGES.ja);
parseJa('1 日');                       // 86400000

// Multi-language: tries each language, returns first successful match
const parseMulti = buildParse([LANGUAGES.en, LANGUAGES.es]);
parseMulti('12 seconds');              // 12000 (english)
parseMulti('-3 minutos');              // -180000 (spanish)

// All built-in languages
const parseAll = buildParse(Object.values(LANGUAGES));
parseAll('2 minutes 15 seconds');    // 135000
parseAll('2 minutos 15 segundos');   // 135000
parseAll('2 分 15 秒');                // 135000
```

## Format

Build a formatter with your options, then use it:

```js
import { buildFormat, LANGUAGES } from '@fabricio-191/ms';

const format = buildFormat();
const num = 1410940000; // ~16 days

format(num);                           // '16d 8h 20m' (default length: 3)

// Custom options
const formatShort = buildFormat({ length: 2 });
formatShort(num);                      // '16d 8h'

const formatLong = buildFormat({ length: 8 });
formatLong(num);                       // '16d 8h 20m 40s'

const formatWithLong = buildFormat({ long: true });
formatWithLong(num);                   // '16 days 8 hours 20 minutes'

const formatEs = buildFormat({ long: true, language: LANGUAGES.es });
formatEs(num);                         // '16 dias 8 horas 20 minutos'

const formatJa = buildFormat({ language: LANGUAGES.ja });
formatJa(num);                         // '16日 8時間 20分'
```

### Format specifiers

* `Y`: year
* `Mo`: month
* `W`: week
* `D`: day
* `H`: hour
* `M`: minute
* `S`: second
* `Ms`: millisecond

```js
const format = buildFormat({ format: 'HS' });
format(4100940000);                    // '392h 1240s'

const formatCustom = buildFormat({ format: 'WDHM', length: 2 });
formatCustom(4100940000);              // '6w 5d'

const formatCustom2 = buildFormat({ format: 'WDHM', length: 4 });
formatCustom2(4100940000);             // '6w 5d 11h 9m'

const formatSmall = buildFormat({ format: 'HS' });
formatSmall(10);                       // '0s' (too small)
```

The default format is `YMoDHMSMs` (without weeks).

## Performance

For maximum performance, use `buildParse` and `buildFormat` which generate optimized functions at build time.

### vs `vercel/ms`

Measured on Node.js v24.11.1 with [tinybench](https://github.com/tinylibs/tinybench).

> **Note:** The benchmarks measure the **generated functions** (what `buildParse`/`buildFormat` return), not the builders themselves.

**Parse:**
| Method | ops/sec | vs `vercel/ms` |
|---|---|---:|
| `vercel/ms` | ~727 | baseline |
| Function generated by `buildParse` (v42) | **~3,199** | **4.4× faster** |

**Format (short, single-unit):**
| Method | ops/sec | vs `vercel/ms` |
|---|---|---:|
| `vercel/ms` | ~2,661 | baseline |
| Function generated by `buildFormat` (v16, l=1) | **~3,750** | **1.4× faster** |

See [docs/jit_optimization.md](./docs/jit_optimization.md) and [docs/comparison.md](./docs/comparison.md) for detailed benchmarks and implementation history.

## API Reference

### `buildParse(language)` / `buildParse(languages[])`

Creates an optimized parse function for the given language(s).

- **language**: `Language` instance or array of `Language` instances
- **Returns**: `(str: string) => number | null`

### `buildFormat(options?)`

Creates an optimized format function with the specified options.

**Options:**
- `long?: boolean` - Use long form (e.g., "2 hours" vs "2h"). Default: `false`
- `length?: number` - Number of units to output (1-8). Default: `3`
- `language?: Language` - Language for unit names. Default: `LANGUAGES.en`
- `format?: string` - Unit format string (e.g., 'YMoDHMSMs'). Default: `'YMoDHMSMs'`

**Returns**: `(ms: number) => string | null`

### `LANGUAGES`

Built-in languages: `en`, `es`, `ja`

### `Language` class

Create custom languages. See [docs/custom_language.md](./docs/custom_language.md).

## Format

```js
const num = ms('16 days 8 hours 20 mins 40 secs');

ms(num); // default length is 3          // 16d 8h 20m
ms(num, { length: 2 });                  // 16d 8h
ms(num, { length: 8 });                  // 16d 8h 20m 40s

ms(num, { long: true });                 // 16 days 8 hours 20 minutes
ms(num, { long: true, language: 'es' }); // 16 dias 8 horas 20 minutos
ms(num, { language: 'ja' });             // 16日 8時間 20分
```
